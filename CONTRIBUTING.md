# Contributing to AFileTidy

Thank you for your interest in contributing to **AFileTidy**.

Contributions, bug fixes, feature suggestions and improvements are welcome.

## Reporting Bugs

Before opening a new issue, please check whether the same problem has already been reported.

When reporting a bug, please include:

- A clear description of the problem
- Steps to reproduce the issue
- Your Windows version
- The version of AFileTidy you are using
- Screenshots, if relevant
- Any error messages you received

## Suggesting Features

Feature suggestions are welcome.

When suggesting a new feature, please explain:

- What the feature should do
- Why it would be useful
- How you expect it to work
- Any examples or screenshots that may help explain the idea

## Contributing Code

If you would like to contribute code:

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test the application carefully.
5. Commit your changes with a clear commit message.
6. Push the branch to your fork.
7. Open a Pull Request.

Example branch names:

- `feature/custom-categories`
- `fix/undo-operation`
- `improvement/file-detection`

## Pull Requests

Please keep Pull Requests focused on a single feature, fix or improvement whenever possible.

Your Pull Request should include:

- A clear description of the changes
- Why the change is needed
- Any relevant screenshots
- Information about how the change was tested

## Code Guidelines

When contributing to AFileTidy:

- Keep the code readable and maintainable.
- Avoid unnecessary dependencies.
- Preserve existing functionality unless the change intentionally modifies it.
- Do not include generated executables or build files in Pull Requests.
- Do not commit personal configuration, temporary files or test data.
- Keep user-facing text clear and consistent.

## Testing

Before submitting a Pull Request, test the relevant functionality on Windows.

For changes related to file organization, make sure:

- Files are placed in the correct folders.
- Existing files are not overwritten unexpectedly.
- Preview behavior works correctly.
- Selected and unselected files are handled correctly.
- Undo functionality continues to work where applicable.
- The application does not delete user files unexpectedly.
