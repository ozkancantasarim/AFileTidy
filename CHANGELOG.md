## [1.0.0] - 2026-09-29

### Added

- Initial stable release of AFileTidy.
- Automatic file organization by file type.
- Folder selection.
- File preview before organizing.
- Individual file selection with checkboxes.
- Select all / deselect all support.
- File size display.
- Automatic category folder creation.
- Undo support for the most recent organization operation.
- Support for common file categories including:
  - Images
  - PSD / Photoshop files
  - Photoshop brushes
  - Documents
  - Spreadsheets
  - Presentations
  - Videos
  - Audio files
  - Archives
  - Fonts
  - Executables
- Portable Windows executable.
- Windows 10 and Windows 11 support.
- Modern desktop interface.
